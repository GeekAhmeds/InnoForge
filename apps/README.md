# Azim Command

**مركز القيادة المالية لأحمد عبدالعظيم (Azim)**: برنامج ديسكتوب بيجمّع كل الشركات اللي بيديرها في مكان واحد، لكل شركة ملفاتها وبياناتها. فيه داشبورد بتتحدث لحظياً، ومساعد ذكي (Claude / OpenAI / Gemini / نموذج محلي) بيرتّب الداتا ويحللها ويطلّع تقارير PDF وExcel وWord.

> من تطوير شركة **Inno Source For Software Solutions**

| | |
|---|---|
| `apps/desktop` | تطبيق الديسكتوب (Electron + React + TypeScript): Windows وLinux حالياً، وMac جاهز للبناء |
| `apps/server`  | سيرفر Azim (Node + Fastify): المزامنة، تخزين الملفات، وخدمة التحديثات التلقائية |
| `scripts/publish-release.mjs` | رفع نسخة جديدة على سيرفر التحديثات |
| `.github/workflows/release.yml` | بناء المثبّتات ونشرها تلقائياً عند عمل tag |

## المميزات

**الشركات والبيانات**
- كل شركة مساحة مستقلة: النشاط، دور عظيم فيها (CFO أو مدير مالي أو مستشار…)، العملة، واللون.
- استيراد بالسحب والإفلات: **Excel (xlsx)، CSV، PDF، Word (docx)، صور (OCR عربي وإنجليزي)، قواعد بيانات SQLite، ونصوص**.
- **مجلد مراقبة لكل شركة**: أي ملف يتحط فيه (مثلاً مجلد المحاسب على الشبكة) بيتسحب لوحده.
- كشف الملفات المكررة ببصمة المحتوى (SHA-256).
- استخراج الجداول من الشيتات والـ PDF وتخزينها كبيانات منظمة قابلة للاستعلام.
- **بحث شامل (Ctrl+K)** جوه محتوى كل الملفات بالعربي والإنجليزي.

**الذكاء الاصطناعي**
- اختيار المزوّد من الإعدادات: **Claude** (الافتراضي `claude-opus-5-5`)، **OpenAI**، **Gemini**، أو **نموذج محلي** (Ollama أو LM Studio) للشركات الحساسة.
- **الكاتب الذكي**: كل ملف جديد الـ AI بيقرأه ويصنّفه (فاتورة، كشف حساب، رواتب، عقد…)، ويحدد الفترة، ويكتب ملخص، ويسحب الأرقام الأساسية للداشبورد.
- **شات بأدوات حقيقية** بيتعامل زي Claude: بيدوّر في الملفات، يقرأها، يجمع ويحسب من الجداول، يسجّل المؤشرات، ينشئ تنبيهات، يسجّل قرارات، و**يولّد تقارير PDF / Excel / Word** بالعربي أو الإنجليزي مع زر لفتحها.
- محادثة لكل شركة أو محادثة مجمّعة لكل الشركات.

**الداشبورد والتحليل**
- مؤشرات لحظية (الإيرادات، المصروفات، صافي الربح، النقدية، المستحقات، الالتزامات…) مع المقارنة بالفترة السابقة.
- رسوم الاتجاه، وتوزيع الملفات حسب التصنيف، ونظرة مجمّعة تقارن كل الشركات.
- **تنبيهات تلقائية**: تغيّر غير طبيعي في أي مؤشر (النسبة قابلة للضبط)، خسارة صافية، ملفات اتعذّر قراءتها، وملفات مكررة.
- **سجل القرارات**: القرار، المبررات، النتيجة المتوقعة، تاريخ المراجعة، والنتيجة الفعلية.

**الأمان والتشغيل**
- **Local-first**: الداتا محفوظة على جهاز أحمد (SQLite)، والمزامنة مع السيرفر اختيارية.
- مفاتيح الـ API مشفّرة بخزنة نظام التشغيل، ومحدش يقدر يوصلها من الواجهة.
- واجهة عربي وإنجليزي مع دعم RTL كامل، ووضع فاتح وداكن.
- **تحديث تلقائي**: أول ما نسخة جديدة تترفع على السيرفر، التطبيق بيعرف خلال ثواني (Server-Sent Events)، ينزّلها في الخلفية، ويظهر زر «إعادة التشغيل والتثبيت».

## التشغيل للتطوير

```bash
cd apps/desktop
npm install
npm run dev          # يشغّل التطبيق مع إعادة تحميل تلقائية
npm run typecheck
npm run dist:win     # مثبّت Windows (NSIS)
npm run dist:linux   # AppImage و .deb
```

## السيرفر (196.221.144.94:9991)

```bash
cd apps/server
cp .env.example .env      # عدّل AZIM_TOKENS و AZIM_ADMIN_TOKEN (openssl rand -hex 32)
docker compose up -d --build
# أو بدون Docker:
npm ci && npm run build && npm start
```

| Endpoint | الوظيفة |
|---|---|
| `GET /api/health` | حالة السيرفر وآخر إصدار |
| `GET /updates/<win\|linux\|mac>/…` | ملفات التحديث للتطبيق |
| `PUT /api/releases/<os>/<file>` | رفع نسخة جديدة (يحتاج `AZIM_ADMIN_TOKEN`) |
| `GET /api/events` | إشعار فوري بالإصدارات الجديدة |
| `POST /api/sync/push` · `GET /api/sync/pull` | المزامنة (تحتاج توكن جهاز) |
| `PUT/GET /api/files/:id` | الملفات الأصلية |
| `GET /api/data/:table` | قراءة البيانات (لتطبيق الموبايل) |

> ⚠️ **مهم:** السيرفر شغال على HTTP. قبل ما تحط عليه داتا حقيقية، حط قدامه HTTPS (مثلاً Caddy أو nginx مع دومين)، وغيّر رابط السيرفر في إعدادات التطبيق وفي `electron-builder.yml`.

## إصدار نسخة جديدة

1. في إعدادات الريبو على GitHub ضيف الـ secrets دي: `AZIM_SERVER_URL=http://196.221.144.94:9991` و`AZIM_ADMIN_TOKEN`.
2. `git tag v0.2.0 && git push origin v0.2.0`
3. GitHub Actions بيبني مثبّتات Windows وLinux، ويرفعها على السيرفر وعلى GitHub Releases. كل نسخة شغالة من البرنامج بتعرف إن في تحديث وبتحدّث نفسها.

يدوياً: `AZIM_SERVER_URL=… AZIM_ADMIN_TOKEN=… node scripts/publish-release.mjs win apps/desktop/dist`

- [ ] توقعات التدفق النقدي وسيناريوهات «ماذا لو» (زيادة أسعار، تأخير تحصيل…).
- [ ] مقارنة الموازنة بالفعلي (Budget vs Actual) مع شرح الانحرافات.
- [ ] مواعيد الالتزامات: الضرائب، الأقساط، تجديد العقود، مع تذكير قبلها.
- [ ] ربط مباشر بقواعد بيانات الشركات (SQL Server / MySQL / PostgreSQL) وبرامج المحاسبة.

- [ ] قفل التطبيق برقم سري، ونسخ احتياطي مشفّر تلقائي.
- [ ] OCR لملفات الـ PDF الممسوحة ضوئياً (حالياً الصور بس)، وإرسال الـ PDF مباشرة لـ Claude.
