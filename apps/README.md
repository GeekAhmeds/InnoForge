# Azim Command

**مركز القيادة المالية لأحمد عبدالعظيم (Azim)**: برنامج ديسكتوب بيجمّع كل الشركات اللي بيديرها في مكان واحد، لكل شركة ملفاتها وبياناتها. فيه داشبورد بتتحدث لحظياً، ومساعد ذكي (Claude / OpenAI / Gemini / نموذج محلي)، وتوقعات للتدفق النقدي، وموازنات، ومواعيد، وتقارير شهرية تلقائية، وتطبيق موبايل.

> من تطوير شركة **Inno Source For Software Solutions**

| | |
|---|---|
| `apps/desktop` | تطبيق الديسكتوب (Electron + React + TypeScript): Windows وLinux، وMac جاهز للبناء |
| `apps/mobile` | تطبيق الموبايل (Expo / React Native): iOS وAndroid |
| `apps/inno-server` | **سيرفر Inno**: سيرفر الشركة المشترك لكل منتجاتها. Azim Command فيه مساحة مستقلة باسم `azim-command` |
| `docs/presentation` | عرض تقديمي تفاعلي وديمو تقدر تجرب فيه البرنامج من المتصفح |
| `scripts/publish-release.mjs` | رفع نسخة جديدة على سيرفر Inno |

## المميزات

### الشركات والبيانات
- كل شركة مساحة مستقلة: النشاط، دور عظيم فيها، العملة، واللون.
- استيراد **Excel وCSV وPDF وWord وصور (OCR) وSQLite**، ومجلد مراقبة لكل شركة، وكشف الملفات المكررة.
- **بحث شامل (Ctrl+K)** جوه محتوى كل الملفات بالعربي والإنجليزي.

### الوكيل الذكي (AI Agent)
- **Agent حقيقي**: بيخطط وبيستخدم أدوات لحد 40 خطوة في الطلب الواحد (الحد ده بيتغير من الإعدادات)، من غير ما يستأذن في كل خطوة.
- **تحليل بيانات بكود**: أداة `run_analysis` بتشغّل JavaScript اللي الوكيل بيكتبه جوه renderer معزول في Chromium، بنظام sandbox ومن غير Node، وكل اتصال بالإنترنت مقفول. بيشتغل على الجداول والمؤشرات نفسها (مجاميع، نمو، pivot، ارتباط، انحدار، متوسط متحرك، قيم شاذة).
- **رسوم بيانية**: في الشات بتبقى تفاعلية (خطي، مساحة، أعمدة، متراكم، أفقي، دائري)، وكل رسم ينفع يتعرض كجدول. وجوه **تقارير PDF / Word / Excel** الرسوم بتترسم SVG وPNG، وفي Excel كل رسم بياخد شيت لوحده ومعاه أرقامه.
- **جداول** في الشات، بتتنسخ لـ Excel بضغطة.
- **بحث في الإنترنت** (Claude): أسعار الصرف، قوانين الضرائب، وأسعار السوق، مع ذكر المصدر.
- **ذاكرة طويلة المدى**: «افتكر إن السنة المالية بتبدأ في يوليو». بتتشاف وتتمسح من الإعدادات.
- **مهام مجدولة**: يومي أو أسبوعي أو شهري. الوكيل بيشتغل لوحده، والنتيجة بتنزل في محادثة، وبتوصل على الإيميل والواتساب.
- **الكاتب الذكي**: كل ملف جديد بيتصنّف، والأرقام بتتسحب منه، ومواعيد العقود والأقساط بتتضاف، وشيتات الموازنة بتتحفظ.

### الربط بالموديلات
| المزوّد | الربط |
|---|---|
| Claude (الافتراضي) | Anthropic SDK بمفتاح API. الموديل الأساسي `claude-opus-5-5`، والسريع `claude-haiku-5-5`، وفيه تحكم في عمق التفكير وبحث في الإنترنت |
| OpenAI | OpenAI SDK بمفتاح API (وممكن تغيّر رابط السيرفر) |
| Google Gemini | `@google/genai` بمفتاح API |
| متوافق مع OpenAI | OpenRouter، DeepSeek، Groq، Together، vLLM، LM Studio (فيه إعدادات جاهزة لكل واحد) |
| موديل محلي | Ollama على `localhost:11434`. الداتا مابتخرجش من الجهاز |

- **موديل سريع** لكل مزوّد للمهام الخلفية، عشان التكلفة تقل.
- **Fallback**: لو المزوّد الأساسي فشل (شبكة، أو حد استخدام، أو عطل)، الوكيل بيكمّل بالمزوّد المفعّل اللي بعده.
- زرار «تحميل الموديلات» بيجيب القايمة من المزوّد.

### التخطيط المالي
- **توقعات التدفق النقدي** لـ 3-36 شهر، محسوبة من اتجاه الإيرادات والمصروفات ورصيد النقدية.
- **سيناريوهات «ماذا لو»** بـ sliders والنتيجة بتتحسب فوراً: تغيير الإيرادات والمصروفات، تأخير التحصيل، نمو يدوي، وبنود استثنائية (شراء ماكينة، قرض…). بيبيّن أقل رصيد وإمتى النقدية تخلص.
- **الموازنة مقابل الفعلي**: الانحراف ونسبته، وهل هو إيجابي ولا سلبي (للمصروفات الأقل هو الأحسن)، وإجمالي من أول السنة لحد دلوقتي، وتنبيه تلقائي عند تجاوز الموازنة.

### المواعيد
- ضرائب، أقساط، تجديد عقود، رواتب، تأمينات. فيه **تكرار** (شهري / ربع سنوي / سنوي) والموعد بيتنقل للدورة الجاية لوحده لما تعلّمه «تم».
- تنبيه على الديسكتوب، وتنبيه في الداشبورد، ورسالة على **الإيميل والواتساب**، وإشعار push على الموبايل.

### التقرير الشهري التلقائي
- لكل شركة: اليوم من الشهر، المستلمين (إيميلات وأرقام واتساب)، اللغة، والصيغة (PDF / Excel / Word).
- التقرير فيه: ملخص تنفيذي بالذكاء الاصطناعي (اختياري)، المؤشرات مقارنة بالشهر اللي فات، الموازنة مقابل الفعلي، اتجاه 6 شهور، توقع النقدية، المواعيد الجاية، التنبيهات، والقرارات اللي محتاجة مراجعة.
- الإيميل عن طريق SMTP، والواتساب عن طريق **WhatsApp Cloud API** من Meta (للإرسال المجدول لازم قالب معتمد).

### الربط المباشر بالأنظمة
- **InnoForge POS** (نظام Inno Source): الربط بيتم بالشبكة الداخلية للـ POS (من POS ← الإعدادات ← الشبكة، على المنفذ 7790). Azim بيدخل كجهاز متصل بمستخدم الـ POS، وبيشغّل تقارير الـ POS نفسها. لما تضيف الاتصال بتتضاف 10 مجموعات بيانات جاهزة:
  - المؤشرات الشهرية (أرباح وخسائر) ← على الداشبورد على طول
  - المبيعات اليومية، والمبيعات حسب المنتج
  - أرصدة العملاء والموردين، وأعمار الديون
  - المصروفات حسب البند، وتقييم ونواقص المخزون، والأقساط المستحقة

  المبالغ بتتحوّل من القروش. الربط اتجرّب على كود سيرفر الـ POS الحقيقي.
- **Inno Source ERP** (innovationsrc.com): ظاهر في الشاشة بعلامة **«لسه — Not Yet»** لحد ما الـ API بتاعه يتربط.
- **SQL Server وPostgreSQL وMySQL/MariaDB وSQLite وOdoo وأي REST API**.
- كل اتصال فيه «مجموعات بيانات» (استعلامات محفوظة) بتتحدث تلقائياً كل X دقيقة:
  - **جدول**: بيدخل في البحث، والـ AI يقدر يحلله.
  - **مؤشرات**: أعمدة `period, metric, value`، أو `period` مع أعمدة أرقام، وبتغذّي الداشبورد على طول.
- قراءة فقط: مسموح باستعلام SELECT واحد، وبيشتغل جوه transaction للقراءة فقط. الأفضل كمان تستخدم مستخدم قاعدة بيانات للقراءة فقط. الـ AI مايقدرش يستعلم غير من الاتصالات اللي إنت سمحتله بيها.

### الأمان والصلاحيات
- **حسابات على سيرفر Inno**:
  - **مدير**: كل الصلاحيات.
  - **محاسب**: يرفع ملفات ويضيف مواعيد للشركات المسموح له بيها بس.
  - **مشاهد**: قراءة فقط.
- السيرفر بيطبّق الصلاحيات (حتى لو حد عدّل في البرنامج)، والبرنامج بيخفي اللي مش مسموح.
- **قفل برقم سري** (4-8 أرقام، scrypt): عند الفتح، وبعد مدة عدم استخدام، وعند قفل الويندوز. فيه حماية من التخمين، والواجهة كلها مقفولة.
- **نسخ احتياطي مشفّر AES-256-GCM** لقاعدة البيانات وكل الملفات والتقارير، يدوي أو تلقائي كل X ساعة مع الاحتفاظ بآخر N نسخة. لو كلمة السر غلط أو الملف متلاعب فيه، الاسترجاع بيترفض.
- مفاتيح الـ API وكلمات السر متشفّرة بخزنة نظام التشغيل.

### التحديث التلقائي
أول ما نسخة جديدة تترفع على سيرفر Inno، كل نسخة شغالة من البرنامج بتعرف في ثواني، وتنزّلها، ويظهر زرار «إعادة التشغيل والتثبيت».

## التشغيل

```bash
# الديسكتوب
cd apps/desktop && npm install && npm run dev
npm run dist:win     # مثبّت Windows
npm run dist:linux   # AppImage و .deb

# الموبايل
cd apps/mobile && npm install && npx expo start      # البناء: eas build -p android|ios
```

## سيرفر Inno (196.221.144.94:9991)

```bash
cd apps/inno-server
cp .env.example .env     # INNO_OWNER_TOKENS و INNO_PUBLISH_TOKEN  (openssl rand -hex 32)
docker compose up -d --build
```

| Endpoint | الوظيفة |
|---|---|
| `GET /api/health` | حالة السيرفر والتطبيقات وآخر إصدار |
| `GET /updates/azim-command/<os>/…` | ملفات التحديث |
| `PUT /api/azim-command/releases/<os>/<file>` | رفع نسخة (`INNO_PUBLISH_TOKEN`) |
| `GET /api/azim-command/events` | إشعار فوري بالإصدارات |
| `GET /api/azim-command/me` | الحساب والدور والشركات |
| `GET·POST·PATCH·DELETE /api/azim-command/users` | الحسابات والصلاحيات (للمدير) |
| `POST /sync/push` · `GET /sync/pull` | المزامنة مع تطبيق الصلاحيات |
| `PUT·GET /files/:id` | الملفات الأصلية |
| `GET /data/:table` | API القراءة للموبايل |
| `POST /push/register` | إشعارات الموبايل (Expo) |

**أول تشغيل:** في البرنامج افتح الإعدادات ← سيرفر Inno، وحط رابط السيرفر وواحد من `INNO_OWNER_TOKENS` وفعّل المزامنة. بعد كده من «الحسابات والصلاحيات» اعمل حساب لكل محاسب، وادّيله الرمز يحطه في برنامجه أو في تطبيق الموبايل.

> ⚠️ السيرفر شغال على HTTP. قبل ما تحط عليه داتا مالية حقيقية، حط قدامه HTTPS (Caddy أو nginx مع دومين).

## إصدار نسخة جديدة
1. في GitHub Secrets ضيف `INNO_SERVER_URL` و`INNO_PUBLISH_TOKEN`، عشان التحديث يوصل للبرامج المتثبتة.
2. زوّد `version` في `apps/desktop/package.json`، واعمل commit فيه `[release]` في الرسالة (أو `git tag azim-v0.3.0`). الـ Actions بيبني Windows وLinux، ويعمل الإصدار `azim-v<version>` على GitHub Releases، ويرفعه على سيرفر Inno. البادئة `azim-v` عشان ماتتلخبطش مع إصدارات منتجات Inno التانية.

المثبّتات: https://github.com/GeekAhmeds/InnoForge/releases
