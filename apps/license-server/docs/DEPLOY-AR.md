# رفع سيرفر التراخيص على السيرفر

سيرفر التراخيص ده موقع بتدخل عليه إنت وموظفينك، والموزّعين والوكلاء كل واحد بحسابه، وكلكم بتطلّعوا منه مفاتيح التفعيل. وفيه كمان العملاء والأسعار والأرصدة والموافقات وسجل بكل حاجة اتعملت.

## الفكرة الأمنية (مهم)

- مفتاحك الأصلي `pos-license-private.pem` **عمره ما بيتحط على السيرفر**.
- السيرفر بيعمل لنفسه مفتاح خاص بيه، وإنت بتدّيله «تصريح» من صفحة المولّد عندك، زي ما بتعمل لأي موزّع.
- لو السيرفر اتسرق أو اتخترق:
  1. ضيف كود التصريح ده لـ `revoked_resellers` في `apps/pos/electron/editions.json`.
  2. اعمل للسيرفر مفتاح وتصريح جديدين.
  3. المفاتيح اللي العملاء خدوها قبل كده بتفضل شغالة.

## اللي محتاجه

- سيرفر Linux عليه Docker و nginx. ينفع سيرفر Hetzner اللي عليه nginx والشهادة.
- دومين فرعي، زي `licenses.0x01source.com`، يشاور على السيرفر.
  - الشهادة الموجودة `*.0x01source.com` بتغطيه.
  - لو هتستخدمه، تأكد إن السجل في الـ DNS بيشاور على السيرفر الصح.

## على سيرفر المكتب inno (الطريقة المعتمدة دلوقتي)

السكريبت ده بيعمل كل حاجة لوحده، **ومش بيغيّر أي حاجة موجودة على السيرفر**:
- بيضيف ملف nginx جديد بس، باسم جديد على بورت 9990 اللي الراوتر بيحوّله أصلاً.
- بيعمل نسخة احتياطية لـ nginx الأول.
- بيختبر الإعدادات قبل ما يشغّلها، ولو الاختبار فشل بيشيل الملف الجديد لوحده.

```bash
curl -fsSLO https://raw.githubusercontent.com/GeekAhmeds/InnoForge/claude/amazing-noether-jd4woa/apps/license-server/deploy/install-inno.sh
sudo bash install-inno.sh
```

- **قبله:** اعمل سجل DNS نوعه **A** اسمه `pos` يشاور على IP المكتب (زي `ls`).
- **بعده:** نفّذ الخطوات اللي بيطبعها في الآخر.
- **النتيجة:**
  - الموقع التعريفي على `https://pos.0x01source.com:9990`.
  - بوابة التراخيص على `https://pos.0x01source.com:9990/portal/`، والدخول من `/login/`.
  - ملفات تحديث البرنامج على `https://pos.0x01source.com:9990/updates/`.
- **للتراجع:** `sudo bash /opt/innoforge/apps/license-server/deploy/uninstall-inno.sh`.

### التحديثات بعد كده
- **نسخ البرنامج للعملاء:** من GitHub ← Releases، علّم النسخة «Latest»، وinno بيسحبها لوحده خلال 10 دقايق.
- **سيرفر التراخيص نفسه:** `sudo bash /opt/innoforge/apps/license-server/deploy/install-inno.sh`. بيعيد التشغيل بآخر كود، والبيانات زي ما هي.

## الخطوات (لأي سيرفر تاني بالطريقة اليدوية)

### 1) جيب الكود وجهّز الإعدادات
```bash
git clone https://github.com/GeekAhmeds/InnoForge.git /opt/innoforge
cd /opt/innoforge/apps/license-server
cp .env.example .env
nano .env
```
في ملف `.env` غيّر:
- `DJANGO_SECRET_KEY`: نص عشوائي طويل. ممكن تطلّعه بالأمر ده: `python3 -c "import secrets;print(secrets.token_urlsafe(50))"`.
- `POSTGRES_PASSWORD`: كلمة سر قوية.
- الدومين في `DJANGO_ALLOWED_HOSTS` و `DJANGO_CSRF_TRUSTED_ORIGINS`.

### 2) شغّل
```bash
docker compose up -d --build
docker compose exec web python manage.py createsuperuser      # حسابك إنت (مدير)
docker compose exec web python manage.py seed_prices          # الأسعار المقترحة — عدّلها بعدين
docker compose exec web python manage.py license_signing init # مفتاح السيرفر — هيطبع «المفتاح العام»
```

### 3) اعمل تصريح للسيرفر
1. على جهازك افتح `license-generator.html`، وحمّل مفتاحك الأصلي.
2. روح على قسم **«تصاريح الموزّعين»** واملا:
   - **المفتاح العام:** اللي طبعه الأمر اللي فات.
   - **الكود:** `SERVER`.
   - **الاسم:** `Inno Source`.
   - كل الباقات، وكل الإضافات.
   - **أقصى مدة:** «من غير حد».
   - **الحدود:** سيبها فاضية.
   - **مدة التصريح:** سنتين.
3. اضغط «إنشاء التصريح»، هينزل ملف `reseller-SERVER.cert`.
4. ادخل على الموقع ← **🛡 توقيع السيرفر**، والصق محتوى الملف. لازم يظهرلك «✓ جاهز يوقّع مفاتيح».

### 4) nginx
```bash
sudo cp nginx-licenses.conf /etc/nginx/sites-available/licenses
sudo ln -s /etc/nginx/sites-available/licenses /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
```
عدّل اسم الدومين ومسار الشهادة في الملف لو مختلفين.

### 5) النسخ الاحتياطي
فيه حاجتين لازم يتعملهم نسخة احتياطية:
- **قاعدة البيانات:**
  ```bash
  docker compose exec db pg_dump -U licenses licenses > backup-$(date +%F).sql
  ```
- **مفتاح السيرفر والتصريح:** موجودين في volume اسمه `keys`. لو ضاعوا، اعمل مفتاح وتصريح جديدين، والمفاتيح القديمة مش هتتأثر.

### التحديث
```bash
cd /opt/innoforge && git pull && cd apps/license-server && docker compose up -d --build
```

## الاستخدام اليومي

**إنت (Inno Source):**
- **الشركاء ← شريك جديد:**
  - تحدد: موزّع، أو وكيل، أو مسوّق.
  - المسموح يبيعه: الباقات والإضافات وأقصى مدة وأقصى حدود.
  - الخصم من سعر القائمة.
  - هل يطلّع مفاتيح على طول، ولا كل مفتاح يستنى موافقتك.
  - حد السحب على المكشوف.
- **من صفحة الشريك:**
  - اعمله حساب دخول (أو أكتر).
  - سجّل أي فلوس يحوّلها في «شحن الرصيد».
- **📨 الطلبات:** توافق على طلبات الشركاء اللي محتاجة موافقة، أو ترفضها.
- **🏷 قائمة الأسعار:** تعدّل الأسعار.
- **📜 سجل النشاط:** كل حاجة اتعملت، مين عملها، وإمتى.

**الموزّع:**
- بيضيف وكلاء تحته، بشرط إنت تكون سامحله بكده.
- مش بيقدر يدّي وكيل أكتر من المسموح له هو.
- بيحوّل لوكلائه من رصيده.

**الوكيل أو المسوّق:**
- **مفتاح جديد:**
  - يختار العميل أو يضيف عميل جديد، ويكتب رقم الجهاز، ويختار الباقة والإضافات.
  - السعر بيظهر وهو بيختار.
  - المفتاح بيطلع، ويقدر ينسخه أو يبعته واتساب.
- **صفحة الترخيص:** تجديد، أو ترقية (بيدفع الفرق بس)، أو نقل لجهاز جديد.
- **الرئيسية:** بتوريه التراخيص اللي هتنتهي خلال 30 يوم، عشان يكلّم العملاء يجددوا.

**الربط بأنظمة تانية:** من **🔌 ربط API** الشريك بيعمل مفتاح، وسيستم بتاعه (موقع مثلاً) يطلّع مفاتيح لوحده.

## أمان الدخول

- **التحقق بخطوتين:** بعد كلمة السر بيطلب كود من تطبيق على الموبايل (Google Authenticator أو Microsoft Authenticator).
  - **إجباري لموظفين Inno Source.** أول ما تدخل، البوابة بتوديك صفحة «🔐 أمان حسابي»: صوّر الـ QR بالتطبيق، واكتب الكود.
  - مع التشغيل بيطلعلك **8 أكواد طوارئ**، احفظها بعيد عن الموبايل. كل كود بيشتغل مرة واحدة لو الموبايل ضاع.
  - **للشركاء:** اختياري لكل شريك (✓ «لازم التحقق بخطوتين لمستخدميه» في صفحة تعديل الشريك). وأي حد يقدر يشغّله لنفسه من «أمان حسابي».
  - **حد ضيّع موبايله:** من صفحة الشريك ← «شيل التحقق»، وهو يشغّله تاني من الموبايل الجديد. ولو نسي كلمة السر: «كلمة سر جديدة»، بتظهرلك مرة واحدة تبعتهاله.
- **القفل:** 5 محاولات غلط لنفس اسم الدخول (أو 20 من نفس العنوان) خلال ربع ساعة بتقفل الدخول ربع ساعة. وnginx كمان بيحدد 10 طلبات في الدقيقة لكل عنوان على صفحة الدخول وفورم الموقع.
  - كل المحاولات (الناجحة والفاشلة) ظاهرة في «أمان حسابي». المدير بيشوف كمان آخر المحاولات الفاشلة لكل الحسابات.
- **⚙ الإدارة المتقدمة (`/django-admin/`):** بتفتح من شبكة المكتب أو Tailscale بس، ومن بره بترجع 403.
  - لو عايز تغيّر المسموح لهم: `ADMIN_ALLOW="…"` قبل أمر التسطيب، و`ADMIN_ALLOW=any` يفتحها للكل (والدخول عليها برضو بخطوتين).
  - الدخول عليها من نفس صفحة دخول البوابة.
- **باقي الحماية:** كلمات السر 10 حروف على الأقل ومش أرقام بس ولا شبه اسم الدخول. الجلسة 12 ساعة. HSTS. الكوكيز Secure وHttpOnly.

## الخصومات

- **خصم الشريك** (من صفحة تعديل الشريك): نسبة ثابتة من سعر القائمة على كل مفاتيحه. ده ربح الموزّع أو الوكيل.
- **خصم خاص لعميل معيّن** (Inno Source بس، من «تعديل العميل»): نسبة بتتخصم **زيادة** على أي مفتاح للعميل ده، حتى لو الشريك هو اللي بيبيعله.
  - **مين بيتحملها:** Inno Source. يعني سعر القائمة 3000، وخصم الوكيل 20% = 2400، وخصم خاص للعميل 50% = الوكيل يدفع 1200.
- **خصم خاص على مفتاح واحد** (زي 90%): خانة «خصم خاص» في صفحة المفتاح الجديد.
  - **إنت:** المفتاح بيطلع على طول بالخصم.
  - **الموزّع أو الوكيل:** لو كتب نسبة، المفتاح **مش بيطلع** وبيتبعت **طلب** في 📨 الطلبات، وفيه الخصم المطلوب. تقدر توافق زي ما هو، أو تغيّر النسبة قبل ما توافق (مثلاً 90% ← 50%)، أو ترفض.
- **«السعر اللي العميل هيدفعه»** (اختياري للشريك): مش بيأثر على الرصيد. بيتسجل بس عشان كشف الحساب يطلّع ربحه (سعر العميل − سعره).

## الحسابات مع الشركاء (التسوية)

كل شريك ليه **رصيد** واحد عند Inno Source، وكل حركة بتتسجل ومبتتمسحش:
- **الرصيد بالموجب:** فلوس **ليه** (دفع مقدم، أو عمولات).
- **الرصيد بالسالب:** فلوس **عليه** (طلّع مفاتيح على الحساب).

**1) الموزّع والوكيل — نظامين، تختار لكل واحد:**
- **دفع مقدم** (حد السحب على المكشوف = 0):
  - يحوّلك فلوس، وإنت تسجلها في «شحن الرصيد» مع رقم التحويل.
  - كل مفتاح بيتخصم من الرصيد، ولما الرصيد يخلص مبيقدرش يطلّع مفاتيح لحد ما يشحن.
  - **مفيش ديون خالص.**
- **آجل** (حد السحب على المكشوف = مثلاً 20,000):
  - يطلّع مفاتيح لحد ما رصيده يوصل لسالب 20,000.
  - آخر الشهر تفتح **📒 كشف حساب** للشهر، وتبعتهوله (طباعة/PDF أو Excel).
  - يدفع، وإنت تسجل الدفعة في «شحن الرصيد»، فالرصيد يرجع صفر.
- **الموزّع ووكلاؤه:** الموزّع بيحوّل لوكلائه من رصيده، وبيحاسبهم هو بنفسه بكشف حساب كل وكيل.
- **مرتجع:** لو ألغيت مفتاح بـ«رجّع السعر»، المبلغ بيرجع لرصيده.
- **تسوية يدوية:** في «شحن الرصيد» اكتب المبلغ بالسالب، زي غرامة أو تصحيح.

**2) المسوّق (بيجيب عملاء وانت اللي بتبيع) — بالعمولة:**
- في صفحة الشريك حط له «عمولة %» (مثلاً 10%).
- في صفحة العميل اختار «جه عن طريق» = المسوّق ده.
- أي مفتاح يطلع للعميل ده بعد كده، أول مرة أو تجديد، بتتضاف للمسوّق **عمولة** في رصيده (10% من اللي Inno Source قبضته).
- لما تدفعله: من صفحته ← «💸 صرف مستحقات»، اكتب المبلغ ورقم التحويل، فبيتخصم من المستحق له.
- لو المفتاح اتلغى بمرتجع، العمولة بتتشال تلقائياً.
- **ملاحظة:** الشريك اللي بيبيع بنفسه مبياخدش عمولة على بيعته. ربحه هو خصمه.

**3) نظرة عامة:**
- صفحة **💰 الحسابات** فيها جدولين:
  - «عليهم لـ Inno Source»: مين عليه فلوس، وقد إيه.
  - «ليهم عند Inno Source»: رصيد مقدم أو عمولات لسه متصرفتش.
- لكل واحد فيهم رابط «كشف».
- **كشف الحساب:** فيه رصيد أول المدة، وكل حركة والرصيد بعدها، والإجمالي حسب النوع، ورصيد آخر المدة. والشريك نفسه بيشوف كشفه من «رصيدي».

## ملاحظة
المفاتيح بتشتغل عند العميل من غير نت، فـ«إلغاء» مفتاح من السيرفر **مش بيقفل البرنامج عند العميل**. الإلغاء بيمنع التجديد والنقل وبيتسجل عندك، والمفتاح بيفضل شغال لحد ما مدته تخلص. لو عايز تقفل البرنامج فعلاً لحد ما يدفع، اديله مفاتيح بمدد قصيرة (شهري مثلاً).
